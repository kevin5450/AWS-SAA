# Troubleshooting

실습 중 발생한 오류는 결과만 적지 않고 아래 형식으로 누적합니다.

```md
## 문제 제목

### Symptom
실제 에러 메시지/현상

### Architecture
어떤 구성에서 발생했는지

### Hypothesis
처음 의심한 원인

### Checks
확인한 명령어/콘솔 위치

### Root Cause
최종 원인

### Fix
해결 방법

### Lesson
다음에 바로 확인할 포인트
```
